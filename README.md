# COE3200: Communication Skills for Computing - Assignment

## 1. Purpose of the Repository
The primary purpose of this repository is to demonstrate how GitHub can be used as a non-verbal communication tool in the IT industry. It showcases the ability to manage source code, maintain documentation, and present a professional profile to collaborators and employers.

## 2. About the Python Script
The repository contains a simple Python script named `hello.py`.
- **Functionality:** When executed, the script prints a friendly greeting message to the console.
- **Language used:** Python 3.x
- **Objective:** To verify the successful setup of the GitHub environment and basic file versioning.
